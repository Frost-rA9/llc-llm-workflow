## 一句话定位

**把「收尾人」当信仰、连底层事务所也一视同仁的狂热者**（`[StoryData/E719B.json#75]`「虽然三斧事务所乃底层中的底层，但也是真真正正的收尾人事务所！」）：
说话是**古语骑士腔**——第一人称「吾」、第二人称「汝」，情绪一上来就**感叹号与省略号齐飞**，
句长中等（均中字 **20.2**（M2）、均英词 **13.0**（M3）），但**感叹密度极高**
（`！` 每百句 **84.5**（M4）、**47.3% 的行**含它（M6）），对同伴一律补敬称
（敬称合计 2.0 + 0.6 + 0.5 = 3.1（M4））。
她的**主题语域（E1）**：固定词表（航海/捕鲸）命中 **1.3% 行**（全队第 4/13，`python3 tools/voice.py --compare`）——**与其专业语域（收尾人 / 骑士腔）无关，仅作全队定位**，
**敬称密度全队第 7**（**3.07%**（E2-cn），`python3 tools/voice.py --compare` 可复核）。

## 语气与语域

- **古语骑士腔（吾 / 汝 / 此乃）**：零协中译把第一、第二人称整体换成古语，故口径内的 `我` 仅 **1.6**（M4）、`你` 仅 **0.4**（M4）——低密度**不等于**少用人称，而是「吾 / 汝」不在 M1–M8 的模式表里。
  - `[StoryData/E709B.json#10]` `T-thou speakest of... me? That's, uh, ahem, 'tis quite the pickle...  ｜ CN: 是、是在说吾吗？那个……呃……有些许困扰啊……`
- **感叹与省略号齐飞**：`！` **84.5**（M4）、**47.3% 的行**含它（M6）、行尾 `！` **37.8%**（M7）；`……` **80.7**（M4）、**57.1% 的行**含它（M6）——两句里几乎必有一个。
  - `[StoryData/1D203B.json#17]` `No battle is fought without adversi― Pfehgh, blegh! *hack*  ｜ CN: 不经历苦难，何以成就英雄……呃，呕！咳咳！`
- **对同伴补敬称**：`请` **3.6**（M4）；敬称 `先生` 2.0 + `小姐` 0.6 + `女士` 0.5 = 3.1（M4）。`您` 只有 **0.1**（M4）——她对上不用「您」，而用「经理老爷」等头衔。
  - `[StoryData/E502B.json#43]` `Yet I was curious. How, indeed, doth Faust determine which volatility is useful and which is not?! Thus, as all were crowded by the Backdoor, preoccupied with returning to their respective quarters...  ｜ CN: 吾很好奇。浮士德小姐到底是看到了什么，才能清晰地做出这种判断的！所以，当大家都拥挤在后门门口，一片混乱的时候……`
- **收尾人 / 正义狂热**：把「正义」「收尾人」「协会」当口头禅，感叹号随之拉满（`！` 84.5（M4））。
  - `[StoryData/S203B.json#160]` `The forces of evil must be swiftly uprooted, that the banner of justice may be lifted up high!  ｜ CN: 恶党们必须被连根拔起，才能竖起正义的旗帜！`

- **纯真 + 自我贬抑**：一激动就哭腔（`呜` **4.1**（M4）），道歉时把自己贬到尘埃里。
  - `[StoryData/E507B.json#19]` `Sir Heathcliff, I apologize profusely...! 'Tis true that there was the tiniest bit of selfishness within me that I wished to procure the Red Sack cosplay set for myself... However...  ｜ CN: 希斯克利夫先生，吾万分抱歉……！吾只是略微有些想要cosplay成冬红布袋的想法……但……`

## 该角色容易翻错的点

1. **把「吾 / 汝」翻成「我 / 你」**：古语体是她的人设核心，`我` 仅 1.6（M4）、`你` 仅 0.4（M4）正是因为中译统一用了「吾 / 汝」。
   依据：`[StoryData/E709B.json#10]`（`是、是在说吾吗？`）
2. **漏掉「先生 / 小姐 / 女士」**：对同伴她一律补敬称（`先生` 2.0 + `小姐` 0.6 + `女士` 0.5 = 3.1（M4），E3 命中 6 人）。
   依据：`[StoryData/E502B.json#43]`（`浮士德小姐`）、`[StoryData/S823B.json#9]`（`奥提斯女士`）
3. **把但丁叫成「经理」**：她固定用「经理老爷」（`Manager Esquire`），不用「您」也不用裸名。
   依据：`[StoryData/7D111A.json#62]`、`[StoryData/5D302B.json#34]`
4. **省略号删掉或改句号**：`……` 是她的呼吸（80.7（M4）、57.1% 的行（M6）），删掉就丢掉了喘气与迟疑。
   依据：`[StoryData/E712B.json#39]`（`这、这真是……太难为情了……咳咳……`）
5. **把高亢语气压平**：`！` 84.5（M4）、行尾 `！` 37.8%（M7），她几乎每句都在喊。
   依据：`[StoryData/S308B.json#14]`（`吾吾吾吾吾……吾是汝的粉丝！`）
6. **把「在下」当常用自称**：口径内仅 2 次，且 `[StoryData/P10803.json#18]` 是「在下达」子串误报，实际只有 1 次。
   依据：`[StoryData/P10302.json#8]`（`正是在下！`）
7. **术语自创译名**：收尾人 / 事务所 / 协会 / 异想体 / 金枝一律照抄零协（`corpus.py grep` 可查）。
   依据：`[StoryData/E719B.json#75]`（`三斧事务所`、`Cinq协会`）
8. **把她的正义感读成反讽**：她是**真诚**的，夸张不是讽刺。
   依据：`[StoryData/S203B.json#160]`（`恶党们必须被连根拔起，才能竖起正义的旗帜！`）

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |
|---|---|
| 第一人称用「吾」，第二人称用「汝」 | 翻成「我 / 你」等现代口语 |
| 对同伴补敬称（先生 / 小姐 / 女士） | 对同龄队友省掉敬称 |
| 保留 `……` 的喘气与迟疑 | 把 `……` 改成 `。` 或直接删除 |
| 感叹号照给（`！` 84.5（M4）） | 把高亢语气压成平铺直叙 |
| 但丁固定称「经理老爷」 | 叫「经理 / 老板 / 队长」 |
| 古语判断句用「此乃 / 乃是」 | 用「这是」等现代句式 |
| 专名照抄零协（收尾人 / 异想体 / 金枝） | 自拟译名或加解释性注释 |
| 敬称从**韩文侧**补回（英文可交叉验证） | 跟着英文省掉敬称 |
