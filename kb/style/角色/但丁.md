## 一句话定位

**边狱公司巴士小队的执行经理**（`[StoryData/PC01B.json#82]`「我是但丁，边狱公司的执行经理」）——一个钟表头、失忆、被推上指挥位的普通人：
说话以**确认与提问**为主，先复述对方的话、再试探性地给出判断；句子短
（均中字 **15.3**（M2）、均英词 **7.8**（M3），均中字在 13 角色中第 2 低，`python3 tools/voice.py --table`），
**省略号几乎成了呼吸**（`……` 每百句 **79.7**（M4）、**70.4% 的行**含它（M6）），
疑问远多于感叹（`？` **36.3**（M4） vs `！` **10.3**（M4））。
他对少数生人 / 年长者保留敬称（`0.2 + 0.3 + 0.0 = 0.5`（M4 敬称合计）），
**敬称密度全队第 9**（**0.51%**（E2-cn））；他几乎没有专业语域（主题词 **0.7% 行**（E1），在 13 角色中偏低，`python3 tools/voice.py --compare`）。

## 语气与语域

- **以疑问推进的确认型口吻**：`？` 36.3（M4）远高于 `！` 10.3（M4），句尾 `吗` 11.5（M4）、`吧` 9.6（M4）；在 13 角色中疑问密度偏高（`python3 tools/voice.py --table`）。
  - `[StoryData/E062X.json#11]` `<So you don't... know about that just yet, right?>  ｜ CN: <所以你也……不知道吗？>`
- **省略号式迟疑与留白**：`……` 79.7（M4）、70.4% 的行（M6），但行尾占比只有 0.1%（M7）——省略号多出现在句中或句首，不是句尾装饰。
  - `[StoryData/E616B.json#10]` `<... What the hell happened?>  ｜ CN: <……为什么，事情会变成这样啊？>`
- **敬称稀少但确有**：`先生` 0.2 + `小姐` 0.3 + `女士` 0.0 = 0.5（M4 敬称合计）、`请` 0.6（M4）；而 `您` 0（M4）——他从不使用「您」。
  - `[StoryData/E010X.json#2]` `<Are you still awake, Ms. Faust?>  ｜ CN: <还没睡吗，浮士德小姐？>`
- **第二人称直呼**：`你` 15.0（M4）、`你们` 2.2（M4）——对绝大多数同伴一律裸名 / 直呼，不加敬称。
  - `[StoryData/S635A.json#0]` `<Are you okay, Heathcliff?>  ｜ CN: <清醒了吗，希斯克利夫？>`
- **情绪上涌时的短促感叹**：`！` 10.3（M4）、`啊` 10.9（M4）、`哈` 1.2（M4）、`呜` 0.2（M4）。
  - `[StoryData/E003I1.json#24]` `<Y-yes, sir?>  ｜ CN: <啊，我在！>`
- **专业语域很淡**：主题词仅 0.7% 行（E1）——航海 / 船只词几乎都出现在他向以实玛利提问、或转述大湖见闻时。
  - `[StoryData/5D101B.json#49]` `<Guys, where's—where's the boat?>  ｜ CN: <船……船去哪了？>`

## 句法特征

| 项 | 指标 | 值 |
|---|---|---|
| 均中字 | M2 | **15.3** |
| 均英词 | M3 | **7.8** |
| 含省略号的行 | M6 | **70.4%**（`……`） |
| 以句号收尾的行 | M7 | **0.1%**（`。`） |
| 疑问 vs 感叹 | M4 | `？` 36.3 ≫ `！` 10.3 |

- **短句为主 + 省略号切碎长句**：均中字 15.3（M2），在 13 角色中第 2 低、仅高于良秀（`python3 tools/voice.py --table`）；他最长的一句也只有 65 字。
  - `[StoryData/E305A.json#8]` `<“I had to ruminate on this dish for a long time. It was an excellent serving in all tangible ways—the smell, the taste, the presentation. Yet, I felt that it was still missing something I couldn’t quite describe with words.”>  ｜ CN: <“这道餐点，我仔细想了很久。不论是从味道、香气或者是呈现方式来说，它都表现得很完美。但是，我总感觉缺点什么我说不上来的东西。”>`
- **「也就是说 / 难道 / 毕竟」式推断**：遇到机制与情报时，他先把结论摆出、再向对方求确认（`吗` 11.5（M4））。
  - `[StoryData/E301A.json#78]` `<So the owner of Eunbong’s… has… turned into one of those Distortion things?>  ｜ CN: <也就是说，那个银凤家的店主就成了……那个……扭曲是吗？>`
- **反问式推进**：拿不准的事用「难道……吗」把判断交还给对话者。
  - `[StoryData/8D102B.json#47]` `<If he's not here to fight... is he here to make an alliance?>  ｜ CN: <如果他不是来战斗的……难道是来结盟吗？>`
- **自我叙述用「我」、群体视角用「我们」**：`我` 462/2759 句（M8）、`我们` 228/2759 句（M8）——比例约 2:1，团队口吻是他的默认立场。
  - `[StoryData/PC11B.json#27]` `<All hands on deck. Leave the lighthouse to Mayors. We have to put a stop to that knight somehow.>  ｜ CN: <把灯塔交给梅厄斯吧，我们要竭尽全力。现在最重要的是阻止那位骑士。>`
- **术语直呼**：金枝 / 异想体 / 扭曲 / 大湖 / 收尾人等专名**直接照用零协译名**，不加解释。
  - `[StoryData/2D301B.json#6]` `<... Because that means we’re getting close to the Golden Bough… right, Faust?>  ｜ CN: <……因为我们在接近金枝……是吗？>`

## 该角色容易翻错的点

> 建议 8 条；**每条必须带** `文件#id` 或统计命令。

1. **漏掉敬称补回——本角色最隐蔽的陷阱**：但丁敬称总量少，但 `씨`/`님` 一个都不能丢；EN 只剩 2 行（KR 23 行、CN 14 行，E2）。
   依据：`[StoryData/E010X.json#2]`（`Ms. Faust` → `浮士德小姐`）、`[StoryData/E301A.json#35]`（EN 裸名 → `李箱先生`）
2. **给维吉里乌斯加敬称**：他对直属上司只叫裸名「维吉里乌斯」，这是人设的一部分，不要自作主张补「先生」。
   依据：`[StoryData/E704B.json#57]`、`[StoryData/E000X.json#31]`
3. **把但丁翻成老练的指挥官**：他的默认姿态是**提问与确认**，不是下命令——`？` 36.3（M4）远高于 `！` 10.3（M4）。
   依据：`[StoryData/1D104B.json#4]`（`这不会疼吧？`）
4. **删掉省略号或改成句号**：`……` 79.7（M4）、70.4% 的行（M6），删掉就丢掉了他的迟疑与留白。
   依据：`[StoryData/E616B.json#10]`（`……为什么，事情会变成这样啊？`）
5. **漏掉「我们」的团队视角**：`我们` 228/2759 句（M8），是「我」的一半；把群体行动全部翻成单数会丢立场。
   依据：`[StoryData/PC11B.json#27]`
6. **把「本人 / 人家」当成自称**：各 1 次且均为子串误报（`李箱本人` / `有钱人家`），不是第一人称。
   依据：`[StoryData/S445B.json#21]`、`[StoryData/S212A.json#23]`
7. **专名自创译名**：金枝 / 异想体 / 扭曲 / 大湖 / 收尾人一律照抄零协（`corpus.py grep` 可查），不得自拟。
   依据：`[StoryData/2D301B.json#6]`（`金枝`）、`[StoryData/E903B.json#100]`（`大湖的鲸`）
8. **忽略钟表头的语音特效**：但丁是钟表头，说话常伴随滴答声与断续，需保留特殊表现而非抹平。
   依据：`[StoryData/E714B.json#79]`（`我说话的声音滴答滴答的……`）

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |
|---|---|
| 用「…… / 吗 / 吧」保留他的迟疑与确认 | 把疑问句翻成斩钉截铁的陈述 |
| 同伴一律裸名直呼（希斯克利夫 / 罗佳…） | 给所有同伴都补「先生 / 小姐」 |
| 对维吉里乌斯也只叫裸名 | 因他是上司就擅自加敬称 |
| 少数敬称（浮士德小姐 / 李箱先生）从韩文侧补回 | 跟着英文把 `씨`/`님` 省掉 |
| 团队行动用「我们」，个人感受用「我」 | 把「我们」全部改写成「我」 |
| 专名照抄零协（金枝 / 异想体 / 扭曲 / 大湖） | 自拟译名或加解释性注释 |
| 受惊 / 疼痛时用短促感叹（`啊` / `哈` / `呜`） | 全篇滥用感叹号 |
| 保留钟表头的滴答 / 断续语音标记 | 把特殊表现抹平成普通台词 |
