## 一句话定位

**以「经理」称呼但丁的冷静分析者**（`[StoryData/P10505.json#7]`「您好，这里是玫瑰扳手工坊的默尔索」——**人格剧情口径**）：
说话像**写报告**——先摆事实、再给结论，短句断言、句号收尾，几乎不用感叹；
句长中等（均中字 **20.2**（M2）、均英词 **13.8**（M3）），但**句号极密**
（`。` 每百句 **115.7**（M4）、**86.2% 的行**以句号收尾（M7）），情绪不外露，
只从 `……`（**23.6**（M4）、**22.1% 的行**含它（M6））与 `嗯`（**7.4**（M4））里漏出；
对上级与生人用完整敬语（`您` 6.3、`请` 2.0（M4）；敬称 0.2 + 0.0 + 0.0 = 0.2（M4 敬称合计））。
他的主题语域 **1.2% 行**（E1，全队第 5，`python3 tools/voice.py --compare` 可复核），
**敬称密度全队第 10**（**0.24%**（E2-cn），`python3 tools/voice.py --compare` 可复核）。

## 语气与语域

- **先陈述后结论的实务/汇报口吻**：句号密度极高（`。` 115.7（M4）、行尾 86.2%（M7）），陈述句为主。
  - `[StoryData/P10508.json#40]` `I will do as you command.  ｜ CN: 请您下令。`
- **分析式/逻辑推理口吻**：推论处用「因此 / 因为 / 所以」把条件一次讲清（`我们` 6.8（M4），M8 计数 57/836）。
  - `[StoryData/S524B.json#20]` `At D Corp., there was a traitor in our midst. Thus, it would be false equivalency to use that experience to gauge the intensity of this mission.  ｜ CN: 在D公司那时，我们之中有一个叛徒。因此并不适合用来和现况作比较。`
- **礼貌但疏离的敬语体系**：`您` 6.3（M4）、`请` 2.0（M4）；敬称 `先生` 0.2 + `小姐` 0.0 + `女士` 0.0 = 0.2（M4 敬称合计）；
  称呼但丁固定用「经理」而非绰号。
  - `[StoryData/E020X.json#59]` `Bonsoir, Manager, and thank you for today’s work. As for tonight’s watch…  ｜ CN: 经理，您辛苦了。今日的值班……`
- **情绪内敛，靠 `……` 与 `嗯` 泄露**：`……` 23.6（M4）、行级 22.1%（M6）；`嗯` 7.4（M4）。
  - `[StoryData/S926A.json#53]` `... Mm. There was no reason not to, Manager.  ｜ CN: ……嗯。我没有不这么做的理由。经理。`
- **自我要求式的内省**：`我` 23.3（M4）；常以「我必须 / 我将」约束自己。
  - `[StoryData/P10510.json#36]` `I must continue to persevere in my studies and grow my repository of knowledge.  ｜ CN: 我必须不懈地精进学业……积攒更多的知识。`

## 句法特征

| 项 | 指标 | 值 |
|---|---|---|
| 均中字 | M2 | **20.2** |
| 均英词 | M3 | **13.8** |
| 含省略号的行 | M6 | **22.1%**（`……`） |
| 以句号收尾的行 | M7 | **86.2%**（`。`） |
| 疑问 vs 感叹 | M4 | `？` 3.3 ≫ `！` 1.6 |

- **短句断言 + 句号收尾**：把动作/判断切成短句，一句一断（行尾 `。` 86.2%（M7）），几乎不堆叠修饰。
  - `[StoryData/S402B.json#61]` `If that is your decision, I will abide by it.  ｜ CN: 如果是决定，那便遵从。`
- **显式逻辑连接词**：结论前先给条件，用「因此 / 因为 / 多亏了」显式衔接（与情绪化队友的最大句法分野）。
  - `[StoryData/S421B.json#12]` `It's thanks to this spy that our course and plans were leaked from the moment we departed.  ｜ CN: 多亏了这个叛徒，我们的路线和计划在出发的时候就已经泄露了。`
- **术语直呼、不加解释**：N公司 / 中指 / 虎标弹 / 圣物 / 晚自习等专名一律照用零协译名。
  - `[StoryData/P10512.json#49]` `We call them Tigermark Rounds(虎標彈). The City makes it rather difficult to make liberal use of ammunition, but these are quite special, even among them.  ｜ CN: 这些被称为虎标弹。虽然都市的子弹价格本就高昂，但这些的价格要更上一层。`
- **反问式澄清**：疑问密度不高（`？` 3.3（M4）），但一旦追问就是要求对方把话说准。
  - `[StoryData/P10514.json#70]` `... What is the meaning of your gaze?  ｜ CN: ……那道视线的意义是什么？`

## 该角色容易翻错的点

1. **漏掉敬称 / 敬语——本角色最大的陷阱**：英文版敬称 0.0%，韩文侧 6.9%，中文仅 0.2%（E2），只跟英文走会系统性丢失人设。
   依据：`[StoryData/S301B.json#49]`（`维吉里乌斯先生`）、`[StoryData/P10514.json#59]`（`Chesed先生`）
2. **把 `……` 删成 `。` 或直接删除**：`……` 是 23.6（M4）、22.1% 的行（M6），删掉就丢掉了迟疑与留白。
   依据：`[StoryData/E914B.json#145]`、`[StoryData/E604B.json#58]`
3. **把 `嗯` 漏译或翻成语气词堆叠**：`嗯` 高达 7.4（M4，62 次），常单独成句，是他「在听/在确认」的信号。
   依据：`[StoryData/E042X.json#40]`、`[StoryData/E707B.json#9]`
4. **翻成情绪化 / 感叹句**：`！` 仅 1.6（M4）、行尾只有 1.1%（M7）；他的高音是极少数例外。
   依据：`[StoryData/E519A.json#63]`、`[StoryData/ES070B.json#16]`
5. **把敬语 `您` 降级成 `你`**：`您` 6.3（M4）与 `你` 6.7（M4）几乎平分，对上级/生人必须用 `您`。
   依据：`[StoryData/P10505.json#38]`、`[StoryData/E919A.json#127]`
6. **删掉显式逻辑连接词**：推论处的「因此 / 因为 / 多亏了」是他的推理骨架，不能口语化成「所以说」。
   依据：`[StoryData/S524B.json#20]`、`[StoryData/S501B.json#24]`
7. **专名自创译名**：N公司 / 中指 / 虎标弹 / 圣物 / 晚自习一律照抄零协（`python3 tools/corpus.py grep` 可查）。
   依据：`[StoryData/P10512.json#49]`（`虎标弹`）、`[StoryData/P10507.json#13]`（`中指`）、`[StoryData/P10510.json#13]`（`晚自习`）
8. **把「经理」改成「老板 / 队长」**：他对但丁的固定称呼是「经理」，不用绰号。
   依据：`[StoryData/E020X.json#59]`、`[StoryData/E061X.json#52]`

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |
|---|---|
| 用「经理 / 但丁经理」+ `您` | 用「老板 / 队长」等自创称呼 |
| 保留 `……` 的迟疑与留白 | 把 `……` 改成 `。` 或直接删除 |
| `嗯` 单独成句、保留为确认信号 | 把 `嗯` 漏译或翻成「嗯嗯啊啊」 |
| 敬称从**韩文侧**补回（EN 常清零） | 跟着英文省掉敬称 |
| 保留「因此 / 因为」等逻辑连接词 | 口语化成「所以说 / 然后」 |
| 专名照抄零协（N公司 / 中指 / 虎标弹） | 自拟译名或加解释性注释 |
| 短句 + 句号收尾 | 把陈述翻成感叹句、滥用 `！` |
| 对生人/上级用 `您`、对同僚用 `你` | 全篇一律用 `你` 或一律用 `您` |
