## 语气与语域

- **叹口气再开口的吐槽腔**：句首常挂一个叹词（`哈` **4.7**（M4）、`嗯` **5.4**（M4）），紧接着 `……` 才进入正题（`……` 行级 **66.0%**（M6））。
  - `[StoryData/E908B.json#83]` `... *sigh* Best you kick me off the bus before push comes to—  ｜ CN: ……哈啊，果然还是在爆发之前由我自己先退出才好……`
- **对同伴与上级补敬称**：`您` **0.7**（M4）、`请` **0.8**（M4）；敬称 `先生` 2.0 + `小姐` 3.4 + `女士` 0.3 = 5.7（M4 敬称合计）。
  - `[StoryData/S823B.json#14]` `Outis. I've also had my share of the war. So hopefully you'll let me put my two Ahns in.  ｜ CN: 奥提斯女士。我也经历过不少战争，让我说两句吧。`
- **大叔式轻快语域（老兄 / 大叔 / 咱们 / 嘛）**：对生人叫「老兄」，对自己叫「大叔」，对小团队用 `咱们`（**0.2**（M4））；句首多用「嘛 / 那什么 / 所以说」缓和。
  - `[StoryData/E401B.json#57]` `Hey, guide bud. Are we really stopping at the beach…?  ｜ CN: 嘿，向导老兄。我们真能在这休息吗……？`
  - `[StoryData/E513A.json#18]` `Seems particularly darker around this area we're in. ... Well, compared to the Smoke War days, it's still bright as a sunny day.  ｜ CN: 在这块地区似乎特别严重……嘛，不过跟烟霾战争那时候比起来，不过是小儿科罢了。`
- **自嘲与战争创伤的底色**：吐槽到一半会突然泄气，把「虫臂 / 战争」当成摆脱不掉的礼物。
  - `[StoryData/E908B.json#50]` `The War isn't over. It never was. And it can't ever be over as long as this... fucking joke of a gift stays attached to my arm.  ｜ CN: 战争……远没有结束。只要这该死的礼物……还在我的手臂上。`
  - `[StoryData/E302B.json#93]` `I cooked up a good few meals using leftovers and cans for my comrades in arms during the war.  ｜ CN: 我曾在战场上多次收集剩下的食物给战友们做罐头料理。`
- **情绪外露方式：感叹少、疑问多**：受惊时才出现 `！`（**6.9**（M4）），日常靠 `？`（**37.3**（M4））推进对话。
  - `[StoryData/E042X.json#2]` `GAH! Holy CRAP!  ｜ CN: 哇！吓我一跳！`
  - `[StoryData/S204B.json#17]` `No, seriously, you’re the only one who thinks that...  ｜ CN: 那个，其实只有你是那么想的……`

## 该角色容易翻错的点

1. **漏掉「先生 / 小姐 / 女士」——本角色最大的陷阱**：英文版几乎丢光（EN 0.1% vs KR 7.2% vs CN 5.4%，E2），只跟英文走会系统性丢失人设。
   依据：`[StoryData/1D301B.json#54]`（`浮士德小姐`）、`[StoryData/S823B.json#14]`（`奥提斯女士`）
2. **把但丁叫成「经理 / 老板」**：他固定用「经理兄」（35 行），这是他的招牌称呼。
   依据：`[StoryData/1D306A.json#87]`（`算了。经理兄。`）、`[StoryData/E042X.json#63]`（`经理兄`）
3. **把「虫子叔」当成他的自称**：那是**别人**对他的叫法，他本人反感并要求少用。
   依据：`[StoryData/E724B.json#66]`（`你是不是该少用虫子叔来称呼我？`）
4. **省略号删掉或改成句号**：`……` 是他的呼吸与迟疑（80.4（M4）、66.0% 的行（M6）），删掉就丢掉了那份泄气感。
   依据：`[StoryData/E908B.json#38]`（`……` 整句）、`[StoryData/P11213.json#107]`（`……`）
5. **把轻快吐槽翻成粗鲁或暴躁**：`！` 仅 6.9（M4）、行尾感叹只有 3.2%（M7）；他的底色是自嘲而非愤怒。
   依据：`[StoryData/S204B.json#17]`（`那个，其实只有你是那么想的……`）
6. **把「咱」当成常用自称**：`咱` 仅 4 次（M4 0.2），且都是「咱们」，不能泛化。
   依据：`[StoryData/2D102B.json#8]`（`咱们要不各退一步`）
7. **术语自创译名**：折断之翼 / 害虫病 / 烟霾战争 / 收尾人 / 异想体一律照抄零协（`corpus.py grep` 可查），不得自拟。
   依据：`[StoryData/1D101A.json#3]`（`折断之翼`）、`[StoryData/E513A.json#18]`（`烟霾战争`）
8. **工坊与烙印术语不统一**：语料中「烙印工坊 / 工坊」并存，新文本须**择一并全篇一致**。
   依据：`[StoryData/P11216.json#45]`（`烙印工坊`）

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |
|---|---|
| 但丁固定称「经理兄」 | 叫「经理 / 老板 / 队长」 |
| 同伴一律补敬称（先生 / 小姐 / 女士） | 对同龄队友省掉敬称 |
| 保留 `……` 的迟疑与叹气 | 把 `……` 改成 `。` 或直接删除 |
| 句首用「那什么 / 所以说 / 反正」缓和 | 用生硬书面连接词 |
| 吐槽保持轻快、自嘲，不刻薄 | 翻成暴躁或愤世嫉俗 |
| 专名照抄零协（折断之翼 / 烟霾战争 / 异想体） | 自拟译名或加解释性注释 |
| 敬称从**韩文侧**补回（EN 常丢） | 跟着英文省掉敬称 |
| 保留「老兄 / 大叔 / 咱们」的大叔口语 | 全篇改成标准书面语 |
