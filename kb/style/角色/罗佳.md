**反问与感叹都密**（`？` 每百句 **51.6**（M4）、**43.1% 的行**含它（M6）；`！` **17.8**（M4）），

## 该角色容易翻错的点

> 建议 8 条；**每条必须带** `文件#id` 或统计命令。

1. **漏掉敬称——她的隐藏陷阱**：罗佳并非完全不用敬称（见「称呼他人的方式」的敬称行）；敬称三层 KR **3.2%** vs EN **0.3%** vs CN **1.5%**（E2），英文常丢，须从韩文侧补回。
   依据：`[StoryData/4D105B.json#53]`（李箱先生）、`[StoryData/E304A.json#98]`（奥提斯女士）
2. **把「咱」当她的常用自称**：全语料仅 5 次（M4 0.3），且全是「咱们」的合音，不能泛化。
   依据：`[StoryData/E721B.json#51]`
3. **把「人家」当第一人称**：2 次（M4 0.1）实为「有钱人家」，并非自称。
   依据：`[StoryData/S611B.json#105]`
4. **删掉或改掉省略号**：`……` 每百句 **62.7**（M4）、**50.7% 的行**含它（M6），是她的卖关子与迟疑。
   依据：`[StoryData/E506B.json#1]`
5. **把反问翻成平铺直叙**：`？` **51.6**（M4）、行尾 `？` **32.6%**（M7）——她靠反问推进对话。
   依据：`[StoryData/E812B.json#97]`
6. **丢掉语气词与拖长音**：`啊`/`吧`/`吗` 极密（M4 见上），句尾 `~` 是招牌。
   依据：`[StoryData/1D105B.json#0]`
7. **把她的玩笑读成刻薄**：`！` 仅 **17.8**（M4），多为兴奋、起哄而非发怒。
   依据：`[StoryData/E302B.json#108]`（我站良秀这边！）
8. **术语 / 专名自拟**：圣愚、后巷、区、愿力、金枝、E.G.O 一律照抄零协（`corpus.py grep` 可查），不得自拟。
   依据：`[StoryData/2D306B.json#30]`（圣愚）、`[StoryData/S216B.json#2]`（愿力）

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |
|---|---|
| 直呼其名、用 `~` 拖长音（但丁 / 以实 / 希斯） | 给同伴硬加「先生 / 小姐」式敬语（她极少用） |
| 保留 `……` 的卖关子与迟疑 | 把 `……` 改成 `。` 或直接删除 |
| 疑问句保留反问语气（`吗` / `吧`） | 把反问翻成平铺直叙的陈述 |
| 用 `啊` / `吧` / `呢` / `哈` 撑起口语感 | 书面化、去掉句尾语气词 |
| 敬称从**韩文侧**补回（KR 3.2% ≫ EN 0.3%，E2） | 跟着英文省掉 `先生` / `小姐` / `女士` |
| 专名照抄零协（圣愚 / 后巷 / 愿力 / 金枝） | 自拟译名或加解释性注释 |
