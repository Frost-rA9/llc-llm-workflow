> 节奏 = **句号收束 + 省略号留白**：行尾 `。` 73.2%（M7）远高于行尾 `……` 15.0%（M7），
> 说明她多半把话讲完，只是中途停顿。`！` 的 M6 仅 1.2%，是全队最低的爆发值（`python3 tools/voice.py --table`）。
> `……` 按连续串计 **1 次**（口径 G5）。
> 语气词的 M7 为 0.0 是**口径定义**所致（M7 = 行尾**恰好**是该模式）；实际语气词多后接标点，
> 故口语感应以 M4/M6 为准。

## 该角色容易翻错的点

> 建议 8 条；**每条必须带** `文件#id` 或统计命令。

1. **把省略号吞掉或改成句号**：`……` 43.3（M4）、39.7% 的行（M6）——省略号是她的停顿，不是可删的装饰。
   依据：`[StoryData/E907B.json#196]`
2. **给她补敬语**：她全语料敬称 0 行（E2-cn 0.00%，全队最低），`您`/`请` 各 0.1（M4）——加敬语即崩人设。
   依据：`[StoryData/P10415.json#18]`
3. **把英文缩写直译成完整词**：`S.Y.N.C.`/`B.A.R.F.` 应转成 `折·脖`/`余·指·尽·折` 这类「中字 + `·`」的强调格式。
   依据：`[StoryData/2D102B.json#16]`、`[StoryData/S210B.json#3]`
4. **用感叹号表现她的凶**：`！` 仅 1.3（M4）、1.2% 的行（M6），全队最低；暴力靠动词而非标点。
   依据：`[StoryData/P10916.json#111]`
5. **把「艺术」当普通名词**：她是审美尺度的持有者，评人评事都用「艺术/美」。
   依据：`[StoryData/E906B.json#101]`、`[StoryData/E906B.json#102]`
6. **让旁人称她「小姐/女士」**：她自己零敬称，别人也多用绰号或直呼。
   依据：`[StoryData/S445B.json#14]`
7. **把她的短句合并成长句**：均中字 **15.2**（M2），全队最低（`python3 tools/voice.py --table`）。
   依据：`[StoryData/S207A.json#15]`
8. **术语自创译名**：收尾人 / 手指 / 食指 / 金枝 / 异想体一律照抄零协（`corpus.py grep` 可查），不得自拟。
   依据：`[StoryData/P10607.json#10]`、`[StoryData/S812A.json#44]`

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |
|---|---|
| 保留 `……` 的停顿与留白 | 把 `……` 改成 `。` 或直接删除 |
| 英文缩写转成 `中字 + ·`（折·脖 / 行·言） | 把 S.Y.N.C. 直译成「同步 / 折颈」 |
| 用短句、裸祈使下命令 | 合并成长句或加缓冲词 |
| 保持零敬语（对她和她说的话） | 给她的台词补「您 / 请 / 先生」 |
| 暴力用动词表达，几乎不用 `！` | 全篇滥用感叹号表现「凶」 |
| 审美判断词照用「艺术 / 美 / 画师」 | 把「艺术」弱化成「东西 / 手法」 |
| 专名照抄零协（收尾人 / 手指 / 食指） | 自拟译名或加解释性注释 |
| 对女儿阿赖耶的段落收敛刀锋 | 把她对女儿的话也翻成冷嘲 |
