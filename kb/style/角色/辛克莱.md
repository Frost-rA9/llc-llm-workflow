## 一句话定位

**都市出身、以「模范生」自我要求的年轻队员**（`[StoryData/E704A.json#54]`「我在学生时代担任副班长，协助班长工作，是一个勤奋的模范学生……」）：
说话**礼貌、迟疑、爱道歉**，句长中等（均中字 **17.8**（M2）、均英词 **10.0**（M3）），
**省略号几乎成了呼吸**（`……` 每百句 **97.8**（M4）、**70.9% 的行**含它（M6））；
对同伴一律补敬称（`先生` 5.2 + `小姐` 6.9 + `女士` 0.8 = 12.9（M4 敬称合计））。
他的**主题语域偏淡**（主题词 **0.9% 行**（E1），在 13 角色中偏低，`python3 tools/voice.py --compare` 可复核），
但**敬称密度全队第 1**（**11.65%**（E2-cn），见下表）。

## 语气与语域

- **礼貌敬语体系（E2-cn 全队第 1）**：`您` **4.3**（M4）、`请` **1.7**（M4）；敬称 `先生` 5.2 + `小姐` 6.9 + `女士` 0.8 = 12.9（M4 敬称合计）。
  - `[StoryData/E306A.json#23]` `T—Thank you, Captain Outis!  ｜ CN: 谢……谢谢您！奥提斯女士！`
  - `[StoryData/P11011.json#89]` `... I guess it can't be helped. Thank you for cheering me up, though.  ｜ CN: ……也没办法呢。谢谢您安慰我。`
- **迟疑、留白的省略号语气**：`……` **97.8**（M4）、**70.9% 的行**含它（M6）——本角色最显眼的节奏标记。
  - `[StoryData/S316B.json#2]` `As you know… I’m not as experienced with fighting like the others…  ｜ CN: 如您所知……我和其他人不一样，几乎没有什么战斗的经验……`
  - `[StoryData/E917B.json#88]` `... Sorry. Just reminded me of something from a long time ago.  ｜ CN: 啊，对不起。我只是想起了一些以前的事情。`
- **自我贬抑与胆怯**：疑问多于感叹（`？` **29.1**（M4） vs `！` **18.7**（M4）），常把「累赘 / 没有经验」挂在自己身上。
  - `[StoryData/S311B.json#54]` `I can’t keep dragging others down.  ｜ CN: 我不能成为累赘。`
  - `[StoryData/P11011.json#72]` `Ugh, don't tease me...  ｜ CN: 呜……请别拿我开玩笑……`
- **受惊时口吃 / 叠字**：`我、我`、`真、真的`、`希……希斯克利夫` 之类的重复，是情绪外露的主要方式。
  - `[StoryData/E922B.json#44]` `Uhm... I-I don't see any difference...  ｜ CN: 呃……我、我觉得看起来都……一样……`
  - `[StoryData/ES280A.json#5]` `R-really?!  ｜ CN: 真、真的吗！？`
- **专业语域偏淡，但专名照抄**：主题词仅 **0.9% 行**（E1），一旦涉及组织/术语则直接照用零协译名。
  - `[StoryData/P11003.json#14]` `That’s right… We’re the Zwei, our clients’ shield.  ｜ CN: 没错……我们可是Zwei，委托人之盾啊。`

| 项 | M4 每百句 | M6 行级% | M7 行尾% |
|---|---:|---:|---:|
| `……` | 97.8 | 70.9 | 36.6 |
| `。` | 42.2 | 37.0 | 33.1 |
| `？` | 29.1 | 26.2 | 19.4 |
| `！` | 18.7 | 13.6 | 10.0 |
| `吗` | 11.6 | 11.5 | 0.0 |
| `啊` | 14.0 | 10.8 | 0.0 |
| `吧` | 7.4 | 7.3 | 0.0 |
| `呢` | 5.3 | 5.3 | 0.0 |

> 补充对称列：`你` **7.5**（M4） + `你们` **0.7**（M4）；`您` **4.3**（M4）。
> `……` 按连续串计 **1 次**（口径 G5），故为 97.8，而非按字符计的两倍。
> 语气词的 M7 为 0.0 是**口径定义**所致（M7 = 行尾**恰好**是该模式）；实际语气词多后接标点（如「……吧。」），
> 故口语感应以 M4/M6 为准。`啊` **14.0**（M4）是本角色最常用的语气词，多与 `……` 连用。

## 该角色容易翻错的点

1. **漏掉「先生 / 小姐 / 女士」——本角色最大的陷阱**：英文版几乎丢光（EN 0.6% vs KR 14.8% vs CN 11.7%，E2），只跟英文走会系统性丢失人设。
   依据：`[StoryData/4D305I.json#5]`（`李箱先生`）、`[StoryData/8D101B.json#28]`（`希斯克利夫先生`）
2. **把同伴称呼写成裸名**：他对几乎所有同伴都固定加敬称，连争吵时也不例外。
   依据：`[StoryData/E406B.json#29]`（`格里高尔先生！`）、`[StoryData/E910B.json#52]`（`良秀小姐`）
3. **把 `……` 删掉或改成句号**：`……` 是他的呼吸（97.8（M4）、70.9% 的行（M6）），删掉就丢掉了迟疑与留白。
   依据：`[StoryData/S316B.json#2]`（`如您所知……我和其他人不一样`）
4. **把他翻成大胆 / 粗鲁的角色**：疑问多于感叹（`？` 29.1 vs `！` 18.7（M4）），且大量使用「对不起 / 抱歉」。
   依据：`[StoryData/2D306A.json#22]`（`啊……抱歉。我肯定是看错了。`）
5. **漏掉口吃 / 叠字**：受惊时首字重复，是人物「怯」的核心标记，不能顺手抹平。
   依据：`[StoryData/E922B.json#44]`（`我、我觉得看起来都……一样……`）
6. **把 `本人` / `人家` 当成常用自称**：各仅 1 次，且实为「其本人」「一户人家」，不是第一人称。
   依据：`[StoryData/S316B.json#20]`、`[StoryData/E703B.json#37]`
7. **敬称名字译法不统一**：英文用罗马音，中文用零协译名，二者不能互推——如 EN `Miss Aeng-du` 对应 CN「樱桃小姐」、EN `Ms. Ryōshū` 对应 CN「良秀小姐」。
   依据：`[StoryData/E516B.json#25]`、`[StoryData/E302B.json#103]`
8. **专业语域加戏或自创术语**：主题词仅 **0.9% 行**（E1），不要为了「专业感」硬塞航海 / 军事词；Zwei、收尾人、心象等一律照抄零协。
   依据：`[StoryData/P11003.json#14]`（`我们可是Zwei，委托人之盾啊`）

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |
|---|---|
| 同伴一律补敬称（先生 / 小姐 / 女士） | 对同伴直呼裸名 |
| 从**韩文侧**补回敬称（EN 常丢） | 跟着英文省掉敬称 |
| 保留 `……` 的迟疑与留白 | 把 `……` 改成 `。` 或直接删除 |
| 受惊时保留口吃 / 叠字（`我、我`） | 把重复字顺手抹平成流畅句 |
| 用 `对不起 / 抱歉` 承接失误 | 翻成理直气壮的反驳 |
| 疑问句用 `吗 / 呢`，语序自然 | 把疑问翻成陈述或加 `！` |
| 专名照抄零协（Zwei / 收尾人 / 心象） | 自拟译名或加解释性注释 |
| 敬称名字按零协译名（樱桃 / 良秀） | 按英文罗马音硬译人名 |
