## 一句话定位

**前军队指挥官出身、习惯下作战简报的罪人**（`[StoryData/E622B.json#9]`「我也收到过关于血魔的报告。那是我还在任职指挥官的时候的事情了。」；`[StoryData/E701A.json#1]`「甚至让我回想起了服役时期的日子。」）：
说话像**下达作战简报**——先给结论、再列条件，句子中等偏长（均中字 **20.5**（M2）、均英词 **13.4**（M3）），
标点上**省略号与句号并用**（`……` 每百句 **53.1**（M4）、**47.9% 的行**含省略号（M6）；行尾 `。` **58.4%**（M7）），
对但丁用完整敬语（`您` **5.1**（M4）），对同伴与敌人则**直呼其名、不加敬称**——
敬称合计 0.0 + 0.0 + 0.2 = 0.2（M4）；另有敬语 `您` 5.1、`请` 2.2（M4）。
她的**主题语域（E1）**：固定词表（船只/航海）命中 **2.1% 行**（全队第 2/13，`python3 tools/voice.py --compare` 可复核）——**与其专业语域相符**（军事 / 船只）；
**敬称密度全队第 12**（**0.17%**（E2-cn），见下表）——她几乎不用「先生/小姐/女士」这套称呼。

## 语气与语域

- **作战简报体：先结论、后条件**：疑问与感叹都高（`？` **19.1**（M4） vs `！` **15.9**（M4）），但语气始终是命令/评估式，而非闲聊。
  - `[StoryData/S502B.json#0]` `Now, men! Clear orders and solidarity are of paramount importance in times like these!  ｜ CN: 好，诸位！在这种危机时刻，最重要的就是明确的指挥与坚定服从的团结！`
- **对但丁用完整敬语，敬语即服从姿态**：`您` **5.1**（M4）、`请` **2.2**（M4）；敬称 `先生` 0.0 + `小姐` 0.0 + `女士` 0.2 = 0.2（M4 敬称合计）。
  - `[StoryData/1D105A.json#9]` `It was felled without a doubt. All thanks to your exceptional command, Executive Manager.  ｜ CN: 它毫无疑问断了气。这都是多亏了经理您那卓越的指挥。`
- **军事 / 船只专业语域**：固定词表命中 **2.1% 行**（E1，全队第 2/13），命中的词是「船 / 航海 / 船长 / 船员 / 大湖 / 甲板 / 大副」。
  - `[StoryData/S502B.json#6]` `A most dimwitted question. A Captain must preserve her strength, or risk putting her subordinates in danger.  ｜ CN: 愚蠢。船长损耗体力会让所有部下陷入危险之中。`
- **口令体 / 集体呼喝**：对部下用「全员 / 全体成员」+ 感叹号（`！` **15.9**（M4）、行尾 `！` **9.4%**（M7））。
  - `[StoryData/S403A.json#26]` `All men, prepare for battle!  ｜ CN: 全员，准备战斗！`
- **屈辱 / 失败时的自贬与撤回**：受挫时会用省略号收句（`……` **53.1**（M4）、**47.9% 的行**含它（M6））。

## 该角色容易翻错的点

1. **把作战简报翻成随便的口语**：她是「命令 / 评估」体，祈使句短而硬。
   依据：`[StoryData/S502B.json#0]`（`明确的指挥与坚定服从的团结`）、`[StoryData/S403A.json#26]`（`全员，准备战斗！`）
2. **对同伴乱补敬称**：她对同伴**直呼其名**，敬称密度全队第 12（**0.17%**（E2-cn））。
   依据：`[StoryData/P10308.json#3]`（`我们不是平民，堂吉诃德。`）、`[StoryData/S518B.json#46]`（`以实玛利，我很清楚……`）
3. **把「经理」自创成「老板 / 队长」**：她对但丁固定用「经理 / 执行经理」+ `您`，且反复强调指挥权归属。
   依据：`[StoryData/1D105A.json#9]`、`[StoryData/S503B.json#45]`（`队长从一开始就是我们的执行经理。`）
4. **漏掉省略号的迟疑**：`……` **53.1**（M4）、**47.9% 的行**含它（M6），删掉就丢掉了她的留白与受挫感。
   依据：`[StoryData/E917B.json#119]`（`那应该……是胶片吧。`）、`[StoryData/E509B.json#47]`
5. **忽略军人出身、把战术术语翻外行**：行军 / 作战方案 / 士气 / 兵力 / 伏兵 / 友军等词照用。
   依据：`[StoryData/E406B.json#5]`（`和工兵队一起指挥作战`）、`[StoryData/E702B.json#82]`（`掌握士兵的状态并进行分析`）
6. **把她的礼貌读成软弱 / 谄媚**：她可以对但丁用 `您`，下一句就下命令、训人。
   依据：`[StoryData/E701B.json#6]`（`我说过都给我好好听从我的作战指挥吧！`）、`[StoryData/S505A.json#30]`
7. **语气词用得太轻佻**：她的高频语气词是 `吗`（**11.5**（M4））、`吧`（**6.6**（M4）），而 `哦` 仅 **0.2**（M4）。
   依据：`[StoryData/E603B.json#91]`（`把话说清楚。`）、`[StoryData/E617B.json#84]`
8. **术语自创译名**：金枝 / 异想体 / 收尾人 / 拉·曼却领一律照抄零协（`corpus.py grep` 可查），不得自拟。
   依据：`[StoryData/S904B.json#87]`（`异想体`）、`[StoryData/7D101B.json#17]`（`拉·曼却领`）

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |

| 军事/航海术语照用（行军 / 兵力 / 船长 / 甲板） | 把战术词翻成日常口语 |
| 专名照抄零协（金枝 / 异想体 / 收尾人） | 自拟译名或加解释性注释 |
| 敬称从**韩文侧**补回（EN 为 0.0%） | 跟着英文完全省掉敬称 |
| 用 `吗 / 吧` 收疑问与劝令 | 堆 `哦 / 呀` 等轻佻语气词 |
