## 一句话定位

**后巷出身的前帮派成员（与死兔帮渊源极深，后离开呼啸山庄加入公司）**（`[StoryData/S619B.json#7]`「死兔帮不是那种无缘无故就杀人的集团」；`[StoryData/S634A.json#17]`「决定要离开呼啸山庄的理由」）：
说话直来直去、情绪先行的街头口吻——句子偏短、疑问与感叹密集（均中字 **18.6**（M2）、均英词 **11.4**（M3）），
**省略号多到成为呼吸**（`……` 每百句 **73.2**（M4）、**60.7% 的行**含它（M6）），**几乎不用敬语**（敬称合计 0.0 + 0.2 + 0.0 = 0.2（M4）；`您` 0.1、`请` 0.3（M4））。
他的**主题语域（大湖/船只类词）很淡**（**0.7% 行**（E1）），**敬称密度全队第 11**（**0.21%**（E2-cn），`python3 tools/voice.py --compare` 可复核）——
他的专业语域是**后巷/帮派**，不是航海，也不是学术。

## 语气与语域

- **情绪先行的街头直球**：疑问与感叹都远高于全队中位（`？` **43.3**（M4）、`！` **19.9**（M4）；13 角色中均属最高档，`python3 tools/voice.py --table` 可复核），
  句尾常直接以 `！`/`？！` 砸下来，不讲缓冲。
  - `[StoryData/S205A.json#12]` `Tell me where your gaffer is! I wanna see ‘im, now!  ｜ CN: 你们的老大在哪！让他马上滚出来！`
- **对谁都用 `你`/`你们`，不用敬语**：`你` **28.8**（M4）、`你们` **3.2**（M4）；
  敬称合计 0.0 + 0.2 + 0.0 = 0.2（M4）；另有 `您` 0.1、`请` 0.3（M4）。且「小姐」几乎全是讽刺（见称呼节）。
  - `[StoryData/S624B.json#35]` `I won't let you fucks stand between us.  ｜ CN: 你们这些混蛋觉得……自己有能耐拦在我跟凯茜之间吗。`
- **省略号是他的呼吸**：`……` 每百句 **73.2**（M4）、**60.7% 的行**含它（M6）、行尾 **24.4%**（M7）——
  迟疑、气喘、被打断、欲言又止全靠它。
  - `[StoryData/E501B.json#61]` `Haah...  ｜ CN: 哈……`
- **街头/帮派语域，不是航海或学术语域**：主题语域（大湖/船只类词）仅 **0.7% 行**（E1），
  日常话题是后巷、帮派、斗殴、酒馆。
  - `[StoryData/E404B.json#45]` `You think me daft? I've had enough years toilin' and brushing with death for the Syndicates of the Backstreets to know that I've got but one life!  ｜ CN: 喂，你把我当傻子吗？我在后巷的帮派生活的时候也有好几次差点死了，我当然知道人命只有一条！`
- **自嘲与自毁式表达**：常把自己说成「混蛋 / 小混混 / 半吊子」，情绪一上来就贬低自己。
  - `[StoryData/S618B.json#28]` `Of course she didn’t. A witless brigand, a scoundrel like me… I’m sure it didn’t matter to Catherine whether I—  ｜ CN: 嗯，确实如此。像我这种混蛋……不管是去是留，对凯瑟琳来说都……`

- **短句 + 碎片化节奏**：均中字 **18.6**（M2）、均英词 **11.4**（M3），一句话常被 `……` 切成几段。
  - `[StoryData/S638B.json#41]` `We have to stop him... we have to...!  ｜ CN: 但我们一定要……阻止他……`
- **反问收尾推进**：爱用「不就好了吗 / 不是吗 / 不就完了吗」把结论甩回给对方（M8：`我` 630/1932）。
  - `[StoryData/E407B.json#37]` `Anyway... all we need to do is catch and kill that prick, innit?  ｜ CN: 总之……我们要做的就是抓住并杀死那个混蛋，不就完了吗？`
- **术语直呼**：呼啸山庄、死兔帮、后巷、中指、拇指等专名一律**照用零协译名**，不加解释。

  - `[StoryData/E503B.json#106]` `Catherine, to be exact. And I call her Cathy.  ｜ CN: 确切说来是凯瑟琳。不过我叫她凯茜。`

## 该角色容易翻错的点

1. **不要因为韩文有 `씨`/`님` 就补敬语**：他的 KR 敬称计数 **3.8%**（E2）里大量是 `아이씨`（烦躁）、`도련님`（少爷）、`아저씨`（大叔）等固定词，零协中文只落 **0.2%**（E2）；对同伴一律 `你`（M4 **28.8**）。
   依据：`[StoryData/7D101B.json#76]`、`[StoryData/S624B.json#35]`
2. **别把「小姐」当礼貌敬称**：他仅有的 4 次「小姐」全是讽刺浮士德（天才小姐 ×2、万事通小姐 ×1，E3）。
   依据：`[StoryData/E051X.json#54]`
3. **省略号不能删**：`……` **73.2**（M4）、**60.7% 的行**（M6），删掉就丢掉了他迟疑 / 气喘 / 被打断的节奏。
   依据：`[StoryData/S638B.json#41]`
4. **不要翻成粗豪的水手腔或学术腔**：主题语域（大湖/船只类词）仅 **0.7% 行**（E1），他的专业语域是后巷帮派。
   依据：`[StoryData/E404B.json#45]`
5. **专名照抄零协**：呼啸山庄 / 死兔帮 / 后巷 / 中指 / 拇指 / 凯茜 一律照用，不自拟、不加注。
   依据：`[StoryData/S620B.json#57]`
6. **但丁用绰号，不用「经理 / 您」**：他叫但丁「钟表头 / 钟表脸」，不加敬语。
   依据：`[StoryData/E065X.json#57]`
7. **「凯茜 / 凯瑟琳」有分工**：亲昵用「凯茜」，正式 / 疏远才用「凯瑟琳」。
   依据：`[StoryData/E503B.json#106]`
8. **别把情绪拉平**：`？` **43.3**（M4）、`！` **19.9**（M4）、`啊` **18.7**（M4）——短促、外露是他的标志。
   依据：`[StoryData/S205A.json#12]`

## 翻译操作清单（Do / Don't）

| ✅ Do | ❌ Don't |
|---|---|
| 对同伴一律用 `你 / 你们` | 补「先生 / 小姐 / 您」 |
| 保留 `……` 的迟疑与气喘 | 把 `……` 删掉或改成 `。` |
| 「小姐」只用于讽刺浮士德 | 把「小姐」当礼貌敬称 |
| 但丁叫「钟表头 / 钟表脸」 | 叫但丁「经理」并加 `您` |
| 专名照抄零协（呼啸山庄 / 死兔帮 / 后巷） | 自拟译名或加解释性注释 |
| 短句 + 高疑问 / 感叹，情绪外露 | 拉平语气、把句子拉长 |
