# 口径 · llc-llm-workflow

> **本文件是翻译工作流的口径定义（仓内自包含）。** 任何取数、统计、写作、收口断言都按本文件执行。
> 版本：**v1.0**（2026-09-20）· 语料基准：零协 Release `2026090501` × 游戏本体 `{kr,en,jp}`（抓取 2026-09-17）
>
> 违反口径 = 产出无法复算 = 无法证明「像零协」。

---

## 一、全局口径 G1–G5

| # | 口径 | 定义 | 违反后果 |
|---|---|---|---|
| **G1** | **逻辑名映射** | 官方文件名去语言前缀（`KR_`/`EN_`/`JP_`）；**跳过** `Info/`、`Font/` 开头；其余目录结构原样保留 | 四语无法按名对齐 |
| **G2** | **对齐键** | `StoryData/*` → `(file, id)`；`RPGSystem/*` → `(file, key, index)`；**必须遍历 `dataList` 列表** | 22 个文件有重复 id（679 条），用 `{id:rec}` 字典会**静默丢记录** |
| **G3** | **文本字段抽取** | 跳过 `id/key/Id/ID/scene/code/type/category`；`model`/`teller` **仅在口吻分析时保留**；`list` 值递归展开（如 `texts[0].text`） | 污染术语统计 / 丢失嵌套文本 |
| **G4** | **语料产物格式** | JSONL，每行 `{"f":逻辑名, "l":语言, "id":键, "k":字段名, "t":文本}` | 工具链全部依赖此格式 |
| **G5** | **口吻基准** | 「句数」= kr 侧有 `model` 且 **en 与 cn 均非空**的记录数（= `L`）；`……` 按 **1 次**计（不按字符计） | 两套口径导致数字互不吻合 |

**编码硬规定**：读取一律 `encoding="utf-8-sig"`（官方三语各有 9 个文件带 UTF-8 BOM，
用 `utf-8` 会因 BOM 报错而被静默丢弃，实测三语共丢 **1,035 行**）；解析失败必须**报错**，不得静默返回空。

**计数单位**：1 条记录 = 1 句 = 1 行；必须遍历 `dataList`（不去重）；文本内 `\n` 视为同一句内换行；
「字符数」= 去掉所有空白后的字符数（含标点）。

## 二、指标口径

### 2.0 两个基底

| 基底 | 定义 | 以实玛利实测 | 用途 |
|---|---|---:|---|
| **`L`**（主口径） | 遍历 `dataList` + kr `model` 匹配 + **en 与 cn 均非空** | **2265** | **M1/M4/M6/M7/M8/E1/E2 的默认分母** |
| **`L_text`**（文本口径） | `L` 且 **en 含 `[A-Za-z]`** 且 **cn 含汉字** | **2174** | 仅 `M2_text`/`M3_text` 对账列 |

> 两者都是「遍历列表」口径（不去重）。去重口径实测 = 2252 / 2161，**不作为口径**。

### 2.1 符号

| 符号 | 含义 |
|---|---|
| `C_all` | `L` 集内 cn 文本总字符数（去空白，含标点）→ **M5 分母** |
| `W_all` | `L` 集内 en 文本总词数（空白切分） |
| `H(p)` | `L` 集内 cn 文本中模式 `p` 的命中次数 |
| `Rh(p)` | `L` 集内**含**模式 `p` 的记录数 |
| `Rt(p)` | `L` 集内**行尾**为模式 `p` 的记录数 |

### 2.2 指标表（M1–M8）

| # | 指标名 | 公式 | 分母 | 保留位 |
|---|---|---|---|---|
| **M1** | 句数 | `L`（并报 `L_text`） | — | 整数 |
| **M2** | 均中字 | `C_all / L` | `L` | 1 位 |
| **M3** | 均英词 | `W_all / L` | `L` | 1 位 |
| **M4** | 每百句密度 | `H(p) × 100 / L` | `L` | 1 位 |
| **M5** | 每千字词频 | `H(p) × 1000 / C_all` | `C_all` | 2 位 |
| **M6** | 行级占比 % | `Rh(p) × 100 / L` | `L` | 1 位 |
| **M7** | 行尾占比 % | `Rt(p) × 100 / L` | `L` | 1 位 |
| **M8** | x / N 计数比 | `H(p)` / `L` 的绝对形式 | `L` | 整数 |

**对账附加列**（**不进交付 md**，仅写入 `build/packs/`）：`M2_text = C_all / L_text`、`M3_text = W_all / L_text`。

**并集/交集口径**：凡「同时满足 a 与 b」，必须先按 `Rh` 求交集再计数，不得用 `H(a) × H(b)` 估算。

**模式表**：29 个模式，分 5 组 —— 标点（`……`/`！`/`？`/`。`）· 自称（我/我们/咱/俺/本人/在下/老夫/人家）·
称呼（你/你们）· 敬语（您/请/先生/小姐/女士）· 语气（呢/啊/吧/呀/哦/啦/嗯/哈/呜/吗）。
`……` 用 `…+` 匹配（按连续串计 **1 次**）。

### 2.3 辅助证据（E1–E3，**不进 M1–M8**）

| # | 证据 | 定义 | 分母 | 用途 |
|---|---|---|---|---|
| **E1** | 主题语域行占比 | `Rh(主题词表) × 100 / L`（1 位） | `L` | 角色专业语域（如航海词） |
| **E2** | 敬称三层行占比 | 行含该语言敬称标记 × 100 / L（1 位） | `L` | **对比 KR/EN/CN，检测「英文丢敬称」** |
| **E3** | 称呼对象行数 | 敬称前中文名的出现行数（整数） | — | 具体被称呼者清单 |

```
E1 主题词表（中文侧）：大湖|白鲸|捕鲸叉|捕鲸枪|鱼叉|水手|船员|船长|大副|甲板|航海|罗盘|船
E2 敬称标记：kr = 씨|님（排除 선생님/아가씨）· en = Mr./Mrs./Ms./Miss/Mister/Ma'am. 或 Sir · cn = 先生|小姐|女士
E3 名称提取：敬称前最长 5 个汉字 → 剔停用字 → 两遍法（2–3 字全收；4–5 字需 ≥2 次）取最长后缀
```

**E2 的用途（最重要的翻译洞察）**：KR 敬称标记远多于 EN——以实玛利实测 **KR 214 行（9.4%）
vs EN 2 行（0.1%）vs CN 145 行（6.4%）**。即 **英文版系统性丢掉了敬称，中译必须从韩文侧补回，不能跟英文走**。

## 三、交付物结构与硬规定

`kb/` 下的 27 份 md 见 `kb/00_索引.md`。角色指南（`kb/style/角色/<中文名>.md`）的 10 节结构见
**`kb/_templates/角色指南.md.tmpl` v1.0（已冻结 2026-09-20）**；速查表见 `kb/_templates/角色口吻速查.md.tmpl` **v1.1（已冻结 2026-09-20）**。

> **冻结规则**：13 份角色指南必须逐节照 v1.0 结构（10 节 + 「敬称行占比·全队横向」子节）；
> 模板改动需升版本号并**重跑全部 13 份**，否则会分裂成两套写法。

### 统一口径的两处硬规定（防止 13 份写法分裂）

| 规定 | 原因 |
|---|---|
| **13 份角色指南必须同时具备：`文件#id` 引用 ≥ 5 处 + 指标 ≥ 3 类** | 模板未冻结时，并行写作会分裂成「只有引用」与「只有指标」两组，13 份之间无法互相比较 |
| **所有指标必须写明公式编号**（如 `均中字 20.5（M2）`） | 避免读者误判口径 |

## 四、断言体系（收口闸门）

任何 md 交付前必须全过；由 `python3 tools/lint_kb.py` 执行。

| # | 断言 | 通过标准 |
|---|---|---|
| **A1** | 引用可解析 | 所有 `文件#id` / `@@model\|file\|id@@` 命中语料；`@@` 残留 **0** |
| **A2** | 数字可复算 | 与 `tools/voice.py` 输出误差 **0**（保留位按 M1–M8/E）。角色指南按「模式行 × 指标列」逐格复算；**速查表（`kb/style/角色口吻速查.md`）** 除逐格外，还复算横向表的「排名/角色」行（角色可在前 3 格）与表格内外所有 `值（M#/E#）` 标注（按同行角色或全队并集判定） |
| **A3** | 术语有来源 | 术语/专名/称呼/自称条目无来源者 **0** |
| **S1** | 引用数 | 角色指南 ≥ **5** 处 |
| **S2** | 指标类数 | 角色指南 ≥ **3** 类（M1–M8） |
| **F1** | 头部规范 | 5 字段齐全（见 §五） |

### 数字写法（A2 的可见性规则）

```markdown
✅ 单指标值：均中字 **20.5**（M2）   行尾"。" 46.5%（M7）   句数 2265（M1）
✅ 表格：表头写指标、行首写模式 → 工具逐格复算
✅ 横向表（含「排名」列）：角色写在第 2 格亦可，逐格复算 E2-cn / 行数（E2）/ E1
✅ 散文与表格里的 `值（M#/E#）`：须等于同行角色（或全队并集）的指标值
✅ 派生值必须写成算式：3.1 + 2.9 + 0.7 = 6.7（M4 敬语合计）
✅ 辅助证据：主题语域 **6.1% 行**（E1）　敬称三层 KR 9.4% / EN 0.1% / CN 6.4%（E2）
❌ 裸小数（不在指标集内）· ❌ 合计不列加数 · ❌ 把 `……` 按字符计（×2）
```

允许的近似：`≈` / `约` / `~` / `±` 前缀，或行内含 `派生` / `合计` → 记 WARN，不算 FAIL。

## 六、权威分层

| 等级 | 定义 | 处置 |
|---|---|---|
| **`零协权威`** | 零协 Release 中已存在的中文 | **不可改**；补丁不得覆盖 |
| **`自拟待确认`** | 本工作流产出、零协尚无的 | 单独成栏；标注生成方式与日期；**零协发布后自动退役** |

**禁止**把「自拟」条目混入「零协权威」栏——否则会把自拟译名固化为「权威」。

## 七、引用与占位符

**写作阶段只允许写占位符，禁止手抄例句**：

```markdown
@@<kr_model>|<逻辑文件>|<id>@@      例：@@이스마엘|StoryData/S709B.json|37@@
```

由 `python3 tools/voice.py --resolve <md>` 回填为 `EN: … ｜ CN: …`。

**引用的唯一合法来源是 `corpus/`**（零协 + 游戏本体三语）。任何外部汉化 / 知识库 / 现成指南
**不得作为引用来源**，也不得写进交付 md；它们只可用于内部对账。

## 八、命令速查

```bash
python3 tools/corpus.py build                    # 索引 + 语料（2187 文件 / 649,488 行）
python3 tools/corpus.py show StoryData/S709B.json # 四语逐条对照
python3 tools/corpus.py grep '<中文>' -l cn       # 某说法零协怎么翻
python3 tools/voice.py --role <角色>              # 单角色全部指标
python3 tools/voice.py --pack <角色>|all          # 证据包 → build/packs/
python3 tools/voice.py --table                    # 速查表数据
python3 tools/voice.py --compare                  # 13 角色横向对比（E2 敬称 / E1 主题语域）
python3 tools/voice.py --resolve <md>             # 回填占位符
python3 tools/lint_kb.py <md>|--all [--strict]    # 收口断言（退出码 0 = 全过）
```
